# Suika / Watermelon Clone for FiveM

**A polished Suika Game clone integrated as a phone application.**
![](./ui/assets/screenshot.png)

## LB-Phone
This script is made for LB-Phone from [LB-SCript](https://lbscripts.com/)

but can easily be adapted to others phone (i guess ?)


## How to install ?
1. Download the latest release.
2. Drag and drop the folder into your `resources` directory.
3. Add `ensure [folder_name]` to your `server.cfg`.

**In summary** : Drop it somewhere and ensure it 👍

## Built With
- **Engine:** [matter.js](https://github.com/liabru/matter-js) (physics).
- **Frontend:** Vanilla JavaScript, HTML and some coffees
